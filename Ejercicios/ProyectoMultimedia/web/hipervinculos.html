Hipervínculos

Los hipervínculos son elementos fundamentales de las páginas web, ya que permiten conectar documentos, acceder a otras páginas y facilitar la comunicación entre usuarios. Mediante ellos podemos navegar por una web, descargar archivos o contactar directamente con otras personas.

A continuación, algunos ejemplos de cómo utilizarlos en HTML.

Principales tipos de hipervínculos

1. Enlace interno a otro archivo

Este tipo de enlace permite acceder a otro documento que se encuentra dentro de nuestro propio proyecto y usaremos el atributo target="_blank" para que esto se haga en una nueva pestaña.

Abrir la página de imágenes

2. Enlace a una sección del mismo HTML

Permite desplazarnos directamente a una parte concreta de la página sin tener que buscarla manualmente. Para ello, asignamos un identificador mediante id y lo utilizamos en el enlace.

Ir al footer

3. Enlace externo a una página web

Permite visitar una página que se encuentra fuera de nuestro proyecto. En este caso, el enlace se abre en la misma pestaña en la que estamos navegando.

Visitar Wikipedia

4. Enlace a un archivo multimedia descargable

También podemos asiganr enlaces para la descarga de determinados archivos. El atributo download indica al navegador que debe intentar descargar el archivo en lugar de abrirlo.

Descargar archivo de audio MP3

5. Enlace a un correo electrónico

Mediante el protocolo "mailto", podemos crear un enlace que abre el programa de correo electrónico del usuario y prepara un nuevo mensaje dirigido a una dirección determinada.

Enviar un correo electrónico

6. Enlace a un teléfono

El protocolo "tel", permite crear un enlace que, al pulsarlo desde un dispositivo compatible, ofrece la posibilidad de llamar al número indicado.

Llamanos

7. Enlace a una red social

Podemos incorporar enlaces a perfiles de redes sociales para facilitar que los visitantes encuentren nuestras cuentas.

Visitar Instagram

8. Integración de WhatsApp

WhatsApp permite añadir enlaces que abren una conversación directamente con un número de teléfono. También podemos incluir un mensaje predeterminado para facilitar el primer contacto.

Contactar por WhatsApp
